# T02 – React + TypeScript Foundation

**Objective:** Establish a working React application and local quality checks.

## Tasks
- Initialize React + TypeScript + Vite and install dependencies.
- Configure TypeScript, ESLint, and npm scripts.
- Create the initial application structure and basic rendering.
- Add a basic application rendering test.

## Verification
- `npm install`
- `npm run dev` starts the app.
- `npm run test:unit`
- `npm run typecheck`
- `npm run lint`
- `npm run build`

## Acceptance criteria
- Application runs locally and all listed checks pass.
