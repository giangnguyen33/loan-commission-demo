# R08: Browser-to-Vendor E2E

**Goal:** Exercise the complete deployed-style path in Chromium: web app -> BFF -> vendor simulator.

## Tasks

- Reuse current Playwright journeys and update startup to run web, BFF, and vendor processes together.
- Configure deterministic test-only vendor scenarios without depending on random failure probability.
- Cover successful quote display, invalid form input, all risk bands, loading, vendor 503, mapped error, retry, and network/timeout behavior where practical.
- Capture Playwright traces, screenshots, and HTML reports on failure.

## Tests / acceptance criteria

- E2E tests prove requests flow through BFF to the independent vendor process, not browser-side interception.
- All Chromium E2E journeys pass locally and in CI.
- Test-only scenario controls are disabled or protected in production.
