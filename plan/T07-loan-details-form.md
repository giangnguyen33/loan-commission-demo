# T07 – Loan Details Form

**Objective:** Capture loan inputs and submit a valid quote request.

## Tasks
- Build a form for loan amount, loan term in months, and risk band.
- Add validation, a Generate Quote action, API-client integration, and duplicate-submission protection.

## Component tests
Cover form rendering, input entry, risk-band selection, required fields, invalid amount and term, API-client invocation, and prevention of duplicate submissions.

## Acceptance criteria
- Form submits valid data and rejects invalid data; all relevant tests pass.
