# T01 – GitHub Repository Setup

**Objective:** Create and initialize the project repository.

## Tasks
- Create the GitHub repository `loan-commission-demo` and set `main` as its default branch.
- Clone it locally; add `README.md` and `.gitignore` and `AGENTS.md` and files in `plan` folders.
- Configure Git identity and the remote; create and push the initial commit.

## Acceptance criteria
- The GitHub repository exists with `main` as default.
- The local project has the correct remote and the initial code is pushed.

## Dependencies
- None.
